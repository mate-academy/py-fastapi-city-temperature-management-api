##  Instructions on how to run
for using this project you have to have an account at weather api
https://www.weatherapi.com/
and use api key in project
```
python -m venv venv
source venv/bin/activate
pip install -r requirements.txt
echo "API_KEY=<your api_key>" > .env
```
## Design choices.

In this project, the functionality was split into separate files for ease of maintenance and possible further improvement.

No simplifications were made during the project implementation and it meets all the initial requirements.
