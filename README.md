# Project description 

FastAPI application for managing city temperatures.

# Technologies used 

1. Python 3.12
2. FastAPI 0.128.0
3. SQLAlchemy 2.0.45
4. Pydantic 2.12.5
5. Alembic 1.17.2

# Installation instructions

1. git clone https://github.com/Bogdan0101/py-fastapi-city-temperature-management-api.git
2. cd py-fastapi-city-temperature-management-api  
3. python -m venv venv  
4. venv/Scripts/activate   # Windows  
4.1. source venv/bin/activate
5. pip install -r requirements.txt  
6. python -m uvicorn main:app --reload  
7. Open http://127.0.0.1:8000
