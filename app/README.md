# City and Weather Management API

Сучасний додаток на FastAPI для управління містами та відстеження історії температур за допомогою асинхронної інтеграції з зовнішнім API погоди.

## Можливості
- **CRUD для міст**: Повне управління містами (Створення, Читання списку, Отримання за ID, Оновлення, Видалення).
- **Служба погоди**: Асинхронно запитує та зберігає поточну температуру для всіх збережених міст з відкритих джерел (`wttr.in`).
- **Історія температур**: Отримання всіх записів температур або фільтрація за конкретним `city_id`.
